# CareerStudy

Repositorio de estudo e evolucao de carreira do Daniel Moliari.

## Contexto
- Ler `CONTEXT.md` para entender de onde vieram as skills e as decisoes tomadas
- A lista principal esta em `skills-study.html` — arquivo HTML estatico com chips organizados por categoria e prioridade
- As fontes originais estao no repo irmao `Apex/career-dossier/` (CVs, LinkedIn plan, master-skills-bank.json)

## Estrutura
```
skills-study.html    — Mapa visual de todas as skills com prioridades
CONTEXT.md           — Origem das skills, decisoes, gaps identificados
CLAUDE.md            — Este arquivo
```

## Regras
- Manter HTML estatico simples (sem build tools, sem frameworks)
- Design system: dark theme, scarlet accent (#ef4444), fonts Space Grotesk + Jakarta + JetBrains Mono
- Icones via Simple Icons CDN (https://cdn.simpleicons.org/)
- Prioridades: P1 (vermelho/essencial), P2 (amarelo/importante), P3 (cinza/bonus)
- Portugues como idioma padrao dos conteudos
