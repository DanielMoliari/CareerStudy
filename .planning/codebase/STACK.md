# Technology Stack

**Analysis Date:** 2026-05-07

CareerStudy is a personal career-study platform migrated from static HTML to Next.js 14 App Router. All pages use `'use client'` because they depend on browser `localStorage` for progress tracking. No backend, no database — purely a client-side SPA served by Next.js.

---

## Languages

**Primary:**
- TypeScript 5.x — all source files under `src/`
- TSConfig target: `ES2017` with `downlevelIteration: true` and `ignoreDeprecations: "5.0"` (intentional, accommodates iterator patterns)

**Secondary:**
- JavaScript (CommonJS) — `scripts/generate-meta.js` (Node.js codegen script, not bundled)

---

## Runtime

**Environment:**
- Node.js (version not pinned; `@types/node: ^20` implies Node 20+)

**Package Manager:**
- pnpm `10.32.1` (pinned with integrity hash in `package.json` `packageManager` field)
- Lockfile: `package-lock.json` present (npm lockfile co-exists — prefer pnpm)

---

## Frameworks

**Core:**
- Next.js `14.2.29` — App Router, `src/app/` directory convention
  - Config: `next.config.mjs` (must stay `.mjs`, not `.ts` — Next.js 14 limitation)
  - Path alias: `@/*` → `./src/*` (defined in `tsconfig.json`)

**Testing:**
- Playwright `^1.59.1` — E2E tests only; config at `playwright.config.ts`
  - Targets Chromium only (`devices['Desktop Chrome']`)
  - `baseURL: http://localhost:3000`; `webServer` spins up `npm run dev` if not running

**Build/Dev:**
- TypeScript compiler `^5` (type-check only via `tsc --noEmit`)
- ESLint `^8` with `eslint-config-next 14.2.29`
- PostCSS `^8` — `postcss.config.mjs`
- Autoprefixer `^10`

---

## Key Dependencies

**UI / Rendering:**
- React `^18` + React DOM `^18`
- Tailwind CSS `^3.4.1` — utility classes; custom design tokens in `tailwind.config.ts`
  - Custom colors: `scarlet` (`#ef4444`), `bg-card` (`#111118`), `bg-elev` (`#1a1a23`), etc.
- `globals.css` defines the full dark-theme design system via CSS custom properties (`--bg`, `--scarlet`, `--fg`, etc.)

**PDF Generation:**
- `@react-pdf/renderer ^4.5.1` — generates downloadable PDF "pocket guides" per skill
  - Always lazy-loaded via dynamic `import()` inside async functions; never bundled upfront
  - Used across 15+ components in `src/components/pdfs/`

**Image Export:**
- `html-to-image ^1.11.13` — present in `package.json` but no import found in `src/`; likely reserved for future visual-export feature

---

## Styling Approach

- **Primary:** CSS custom properties + hand-written CSS in `src/app/globals.css` (9 KB)
- **Secondary:** Tailwind CSS utility classes for layout/spacing
- **No CSS Modules** — single global stylesheet is the design system
- Font loading: Google Fonts via `<link>` in `src/app/layout.tsx` (not `next/font`, intentional)
  - Families: `Plus Jakarta Sans` (body), `Space Grotesk` (headings), `JetBrains Mono` (code/labels)

---

## Data Layer

- No database or backend. All data is static TypeScript objects.
- Skill content lives in `src/data/content/{domain}/{slug}.ts` (~218 skills across 11 domains)
- `src/data/content/meta.ts` is auto-generated by `scripts/generate-meta.js` — never edit manually
- `src/data/skills.ts` exports `ALL_SKILLS`, `SKILL_BY_SLUG`, `DEPENDENCIES`, `iconUrl()`
- Progress state persists in `localStorage` key `careerstudy.progress.v1` via `src/hooks/useProgress.ts`

## Build Scripts

```bash
npm run dev      # next dev → http://localhost:3000
npm run build    # next build (production bundle)
npm run start    # next start (serve production build)
npm run lint     # next lint (ESLint)
node scripts/generate-meta.js   # regenerate src/data/content/meta.ts after skill edits
npx tsc --noEmit                # type-check without emitting
```

## Configuration Files

| File | Purpose |
|------|---------|
| `next.config.mjs` | Minimal Next.js config (no special options set) |
| `tsconfig.json` | TypeScript — ES2017 target, `bundler` moduleResolution, `@/*` alias |
| `tailwind.config.ts` | Custom color tokens; content glob: `./src/**/*.{js,ts,jsx,tsx,mdx}` |
| `postcss.config.mjs` | tailwindcss + autoprefixer plugins |
| `playwright.config.ts` | E2E test config — Chromium only, port 3000 |
| `.gitignore` | Ignores `.next/`, `node_modules/`, `.env*.local` |

---

## Platform Requirements

**Development:**
- Node 20+, pnpm 10.x
- `npm run dev` for local server on port 3000
- `node scripts/generate-meta.js` required after any skill content change

**Production:**
- Standard Next.js static/SSR deployment
- No environment variables required (no secrets — all data is static)
- `start.sh` at repo root is a legacy Python HTTP server for the old HTML files — not used by Next.js
